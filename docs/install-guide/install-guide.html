Step by step
Installing the app

Two ways to get the install card

Most people never need the second way — the card appears on its own. Use it only if the card closed before you could tap it.

1

Open the link and tap Install

Open your browser and go to alu-expense-tracker.web.app. The app opens, and a small card appears at the top of the screen:

Install Student Expense Tracker — tap Install on the card.

If you see the sign-in page instead of the card, look at the very top of the screen before scrolling — the card floats over the app.
2

Missed the card? Use the menu

No problem. Tap the menu button at the top-right of your browser — the three dots.

A list of options drops down. Tap Install and create shortcut.

On some phones the same option is called Add to Home screen. Both do the same thing.

Step by step
Finishing the install

Confirm, then open the app

One confirmation window, and the tracker is on your home screen.

3

Tap Install in the window

A window titled Install app opens with the app name and its address.

Tap Install. Choose Install on device if your phone offers you the choice between installing and creating a shortcut.

The window closes and the app appears on your home screen as a green circular icon named ALU Expense.

4

Open ALU Expense and sign in

Tap the new icon. It opens full screen, without the browser bar — that is how you know it is installed properly.

Sign in with the email and password you used on the website. New here? Tap Create Account, then set up your budget and record your first expense.

From now on, use the icon — not the browser. Your records are saved to your account, so the phone and your computer always show the same figures. Signing in on a second device brings both copies together instead of replacing one with the other.

Help
If something does not work

Before you give up on it

These four checks fix almost every failed install.

Open the link in a real browser, not inside WhatsApp, Facebook or Instagram.
If you opened it inside another app, tap the menu there and choose “Open in browser”.
Wait for the page to finish loading — the install card appears a moment after the app itself.
Update your browser if the menu has no install option at all.

“I installed it, but I still see the browser bar.”

You added a shortcut instead of installing. Remove that shortcut, open the link again and choose Install app. The correct version opens edge-to-edge, with no address bar.

“The card is gone and the menu has no install option.”

You can keep using the tracker in the browser — nothing is lost. To install later, close the other browser tabs, open alu-expense-tracker.web.app again and wait a few seconds.

“I forgot the password I used on the website.”

On the sign-in screen tap Forgot password?, enter your email and a reset link is sent to you. The newest link is the one that works — asking for another cancels the previous one.

“Does installing copy my records onto the phone only?”

No. Your records live in your account, not on the phone. The app is only a window onto them, so nothing is lost if you change phones or reinstall.

Still stuck? Open the app, go to Help and send a report — it reaches the team with your app version and the page you were on.
